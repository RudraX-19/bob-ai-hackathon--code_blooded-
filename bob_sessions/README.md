# bob_sessions/

Upload IBM Bob IDE task session exports here for judging.

## Steps to export:
1. Bob IDE → Views → History
2. Select a task → click task header
3. Screenshot the session consumption summary
4. Click Export task history icon → download .md file
5. Upload both files here

Required files:
- `task-NNN-screenshot.png`
- `task-NNN-history.md`
